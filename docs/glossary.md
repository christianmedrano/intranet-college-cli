# Glosario del Dominio Escolar

> Todo término nuevo debe registrarse aquí antes de usarse en una spec.
> Fuente de referencia del sistema educativo peruano: CNEB y SIAGIE.

## Estructura académica

| Término | Definición |
|---|---|
| **Nivel educativo** | Etapa del sistema: Inicial, Primaria o Secundaria. |
| **Grado** | Año de estudios dentro de un nivel (por ejemplo, 3.º de Primaria). |
| **Sección** | Grupo de alumnos dentro de un grado (por ejemplo, 3.º A). |
| **Curso / Área curricular** | Asignatura o área de aprendizaje con un docente asignado. |
| **Año académico** | Período anual que contiene la configuración de niveles, grados, secciones y períodos. |
| **Período académico** | Bloque de evaluación dentro del año. Puede ser bimestral (4) o trimestral (3), según configuración. |
| **Bimestre** | Período de evaluación cuando el año se divide en cuatro. |
| **Trimestre** | Período de evaluación cuando el año se divide en tres. |
| **Calendario académico** | Configuración de períodos de un año lectivo, con fechas y estados. |

## Evaluación

| Término | Definición |
|---|---|
| **CNEB** | Currículo Nacional de la Educación Básica. |
| **Competencia** | Capacidad de actuar de forma pertinente ante situaciones diversas. |
| **Capacidad** | Recurso que el estudiante moviliza para desarrollar una competencia. |
| **Calificación literal** | Escala oficial: `AD`, `A`, `B`, `C`. Única válida para actas y certificados. |
| **AD — Logro destacado** | El estudiante evidencia un nivel superior al esperado. |
| **A — Logro esperado** | El estudiante evidencia el nivel esperado. |
| **B — En proceso** | El estudiante está próximo a alcanzar el nivel esperado. |
| **C — En inicio** | El estudiante muestra un nivel mínimo o intermedio de progreso. |
| **Nota final** | Resultado consolidado de un período. Su fórmula se define en la spec académica. |
| **Acta** | Documento oficial con las calificaciones finales de un grupo. |
| **SIAGIE** | Sistema de Información de Apoyo a la Gestión de la Institución Educativa, administrado por el MINEDU. |

## Comunidad educativa

| Término | Definición |
|---|---|
| **Alumno** | Estudiante matriculado en la institución. |
| **Docente** | Profesional que dicta uno o más cursos. |
| **Apoderado** | Persona responsable legal del alumno. En la interfaz se muestra como «Padre/Apoderado». |
| **Director** | Autoridad académica de la institución. |
| **SuperAdmin** | Rol técnico de administración del sistema. |
| **Tutor** | Docente responsable de una sección, encargado del seguimiento. |

## Asistencia

| Término | Definición |
|---|---|
| **Presente** | El alumno asistió dentro del horario de tolerancia. |
| **Tarde** | El alumno llegó después del inicio de la jornada. |
| **Falta justificada** | Ausencia con justificación aprobada por un docente o la dirección. |
| **Falta injustificada** | Ausencia sin justificación aprobada. |
| **Umbral de alerta** | Cantidad de inasistencias que dispara una alerta al apoderado. Se define en la spec académica. |

## Gestión administrativa

| Término | Definición |
|---|---|
| **Matrícula** | Proceso por el cual un alumno queda inscrito en un grado y sección para un año académico. |
| **Pensión** | Monto periódico que paga el apoderado por el servicio educativo. |
| **Cuota** | Cada vencimiento o pago parcial asociado a una pensión. |
| **Estado de cuenta** | Resumen de cargos y pagos de un alumno. |
| **Constancia** | Documento que acredita una situación puntual (estudios, vacante, conducta). |
| **Certificado** | Documento oficial que acredita estudios culminados. |

## Aula virtual y comunicación

| Término | Definición |
|---|---|
| **Material** | Recurso pedagógico publicado por un docente para un curso y período. |
| **Anuncio** | Mensaje institucional segmentado por nivel, grado, sección o rol. |
| **Mensajería interna** | Canal controlado entre docentes y apoderados dentro de la intranet. |
